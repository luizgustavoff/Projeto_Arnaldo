O que é o StravaClone:<br>
O StravaClone foi desenvolvido com o objetivo de trazer inovação, soluções tecnológicas e dinâmismo. Trazendo diversas propostas inovadoras atreladas a atividade física, onde praticar e interagir sobre as atividades físicas realizadas geram recompensas.<br>
O StravaClone é uma aplicação Mobile, que visa motivar e induzir seus usuários a realizarem atividades físicas como: Corrida, Caminhada, Ciclismo entre outros e se relacionarem, possubilitando a criação de grupos e comunidades onde conectaremos instrutores á alunos(as) oferecendo uma interface intuitiva para todos.   

O que nos Motivou a desenvolver o StravaClone:  
Nós, da equipe eramos usuários de um aplicativo semelhante no mercado e percebemos certas limitações e uma falta de inovação nas propostas de manter os usuários praticando atividades físicas e se relacionando.

## ⚙ Funcionalidades e Demonstração da Aplicação

### Funcionalidades Principais

* *[Funcionalidade 1]:* Cadastro e autenticação de novos usuários.
* *[Funcionalidade 2]:* Geração de relatórios em forma gráfica com base nos dados de atividades físicas para avaliar a evolução do usuário.
* *[Funcionalidade 3]:* Interface responsiva para acesso via dispositivos móveis.
* *[Funcionalidade 4]:* Criação de grupos e comunidades dentro do aplicativo.
* *[Funcionalidade 5]:* Canais de conversa e divulgação de eventos.
* *[Funcionalidade 6]:* Conta de Recompensas.
* *[Funcionalidade 6]:* Calculo de métricas semanais (distância, tempo, ritmo, calorias), para noção de um desempenho consolidado.

### ⬇️ Instalação Local (Passo a Passo)
Caso queira rodar o projeto em sua máquina local, siga os passos abaixo:

1.  **Clone o Repositório:**
    ```bash
    git clone https://github.com/luizgustavoff/Strava_Clone.git
    ```
2.  **Entre no Diretório:**
    ```bash
    cd Strava_Clone
    ```
3.  **Instale as Dependências:**
    ```bash
    # Exemplo para Node.js:
    npm install
    # Exemplo para Python:
    pip install -r requirements.txt
    ```
4.  **Execute a Aplicação:**
    ```bash
    # Exemplo:
    npm start
    ```
